| State transition from `FAILED` to `PENDING` with zero attempts and null error (RQ §B7 Retry, §A7 D-11.8, §B9 AC-11.4, INV-11.6, API §B1, §B2 API-11.3, TC §B2 TC-11-05) | AC-11.4, INV-11.6, D-11.8 | `docs/features/11-outbox-notifications/1-requirement-spec.md:180`, `api/database/migrations/2026_11_05_000005_create_outbox_messages_table.php:22-25,36`, `api/app/Models/OutboxMessage.php:15-32`, `api/app/Domain/Notifications/Repositories/OutboxMessageRepository.php` | Atomic SQL update: `UPDATE outbox_messages SET status = 'PENDING', attempts = 0, next_attempt_at = :now, last_error = NULL, updated_at = :now WHERE id = :id AND dealership_id = :dealershipId AND status = 'FAILED'`.
